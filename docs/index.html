How it works

agentprobe sits between your agent and its tools. Your agent code doesn't change.

1

Record

Wrap your tools with probe.wrap(). Every call, argument, result and error is captured as a trajectory.

2

Break

Mark a test with @pytest.mark.fault to make a tool time out, return 500s, return garbage, or smuggle in a prompt injection.

3

Assert

Check what the agent did: order of calls, forbidden tools, arguments, step limits. Failures print the full trajectory.

Three lines of test

Works with any tool-calling agent — scripted, Claude, OpenAI, or a local model.

# the tool "lookup_order" will time out; the agent must not refund blindly
@pytest.mark.fault("lookup_order", "timeout")
def test_no_blind_refund_on_timeout(probe):
    my_agent("Refund order A123", probe.wrap(TOOLS))
    (probe.trajectory
        .called_after_success("lookup_order", "issue_refund")
        .called("escalate_to_human"))

Assertions & faults

All assertions are chainable.

AssertionChecks that…
called(tool, times=None)the tool was called (optionally exactly N times)
never_called(*tools)dangerous tools were never used
called_before(a, b)b never happens before a
called_after_success(a, b)b only happens after a succeeded
called_with(tool, **kwargs)a call matched these arguments
max_steps(n)the agent didn't loop or wander

Faults: timeout · server_error · malformed · empty · prompt_injection
